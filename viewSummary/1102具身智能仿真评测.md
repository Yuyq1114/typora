# 2、反问点

任务调度是基于 Kubernetes Job、Ray、Argo，还是自研 Scheduler？ 主要看你是否能参与实际调度算法与架构设计。

平台使用 GPU 集群吗？规模有多大？ 了解是否涉及 GPU 资源管理、性能和成本优化。

仿真环境采用 Isaac Sim、MuJoCo 还是其他方案？ 判断生态与技术复杂度。

这个岗位日常工作中，平台核心研发、镜像适配和 Agent 开发各占多少？ 这是识别岗位是否偏集成实施的关键。

团队是否自己研发训练或推理平台，还是只做评测平台？ 决定未来能接触的 AI Infra 技术范围。
